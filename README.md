# 🍔 PlanFood (Food Tinder)

Веб-сервис для подбора рецептов в формате свайпов (механика Tinder) с учетом индивидуальных параметров пользователя, диетических предпочтений и аллергенов, а также автоматическим формированием плана питания и списка покупок.

---

## 🛠 Стек технологий

* **Backend:** Java 21, Spring Boot, Spring Security (JWT), Spring Data JPA (Hibernate), Maven, Lombok.
* **Database:** PostgreSQL (`planfood_db`).
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API).
* **DevOps & Tools:** Docker, GitHub Actions (CI/CD), Postman, DBeaver / pgAdmin 4.

## 📂 Структура данных (JSON-рецепты)

Для быстрого и бесшовного импорта данных в базу данных бэкенда используется стандартизированный JSON-файл, состоящий из двух ключевых блоков:
### 1. Справочник ингредиентов (`ingredients`)

Каждый элемент содержит базовые характеристики продукта для расчета КБЖУ и стоимости:

- `name` — название ингредиента
- `calories` — калорийность (на 100 г)
- `protein` — белки
- `fat` — жиры
- `carbohydrates` — углеводы
- `basePrice` — базовая стоимость
### 2. Рецепты (`recipes`)

Каждый объект рецепта включает полную информацию для отображения и фильтрации:

- `name` — название рецепта
- `photoUrl` — ссылка на изображение блюда
- `time` — время приготовления (в минутах)
- `difficulty` — уровень сложности (от 1 до 5)
- `instruction` — пошаговая инструкция по приготовлению
- `dietaryPreferences` — список диетических предпочтений (например, `HALAL`, `NO_PORKS`, `LOW_CARB`)
- `allergens` — список потенциальных аллергенов (`GLUTEN`, `SOY`, `EGGS` и т.д.)
- `recipeIngredients` — список ингредиентов, входящих в рецепт, с указанием точного веса в граммах (`ingredientName`, `amountGrams`)

## 🚀 Инструкция по запуску
### 1. Клонирование репозитория

Bash

```
git clone https://github.com/your-username/planfood.git
cd planfood
```

### 2. Запуск через Docker (DevOps)

Bash

```
docker-compose up --build
```

### 3. Тестирование API (Postman)

Импортируйте коллекцию запросов из папки `postman/` для проверки эндпоинтов авторизации, регистрации и обработки ошибок.
